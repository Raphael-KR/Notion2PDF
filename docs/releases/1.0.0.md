# Notion2PDF 1.0.0 (build 3)

개인용 로컬 Notion/HTML → PDF 도구의 첫 1.0 릴리스입니다.

## 주요 기능과 수정

- Notion URL/page ID와 정적 HTML/CSS를 WeasyPrint로 A4 PDF로 변환합니다.
- 한글 Pretendard 폰트, 블록 색상, 목차, 표, 다단, 체크리스트, 콜아웃, 코드 등을 지원합니다.
- macOS 앱에서 링크 입력, 저장 위치 선택, 선택적 중간 HTML 저장, 결과 안내를 제공합니다.
- 짧은 항목명을 가진 2열 표의 첫 열 너비와 2단 배치의 우측 넘침을 수정했습니다.
- 짧고 전체가 굵은 문단형 소제목이 다음 내용과 페이지 경계에서 떨어지는 문제를 수정했습니다.
- 앱의 `--version` 조회와 프로젝트 경로를 보존하는 `/Applications` 설치·등록 스크립트를 추가했습니다.

## 검증

- 실제 문서의 동일한 원본 스냅샷으로 생성한 20쪽 PDF 전체를 이미지로 검수했습니다.
- 제목·소제목과 다음 내용 58쌍을 검사했으며, 페이지 분리는 5곳에서 0곳으로 줄었습니다.
- 원본 텍스트 382개 구간 보존, PDF 텍스트 누락·본문 영역 밖 넘침·빈 페이지 없음, 표·2단 배치와 한글 폰트 임베딩을 확인했습니다.
- 검증 환경: macOS Apple Silicon, 프로젝트 로컬 Python 3.14, WeasyPrint 67.0.

## 설치와 사용 범위

- 소스 기반 로컬 도구입니다. 저장소, 프로젝트 `.venv`, Homebrew 라이브러리, 인증된 Notion CLI(`ntn`)가 필요합니다. 설정 방법은 README를 참고하세요.
- 의존성을 준비한 후 `zsh scripts/install_macos_app.sh`로 `/Applications/Notion2PDF.app`을 설치·등록합니다.
- 설치 앱은 프로젝트의 Python/CSS 파일을 참조합니다. 프로젝트를 이동하면 새 위치에서 설치 스크립트를 다시 실행하세요.
- 독립 실행형 설치 앱, Developer ID 서명·공증 배포판 또는 Mac App Store 배포판이 아닙니다.
- 모든 Notion 문서의 레이아웃이나 원본 UI의 정확한 열 너비를 보장하지 않습니다. 일부 레이아웃은 보수적인 휴리스틱을 사용합니다.
- 긴 코드 블록은 여러 페이지로 나뉩니다. 소제목을 다음 내용과 함께 배치하면 페이지 수와 여백이 늘 수 있습니다.
- 이번 릴리스에서 앱의 전체 대화상자 흐름·키보드·VoiceOver 검증은 수행하지 않았습니다.
- 비공개 Notion 원본, 생성 PDF/HTML, 인증정보, 개인 로그는 릴리스에 포함하지 않습니다.

## 버전 관리

앱의 `Contents/Info.plist`를 버전 정본으로 사용합니다. 제품 버전은 `1.0.0`, 빌드 번호는 `3`, Git 태그는 `v1.0.0`입니다. 이후 호환 수정은 patch, 기능 추가는 minor, 비호환 변경은 major 버전으로 관리하고 빌드 번호는 증가시킵니다.
