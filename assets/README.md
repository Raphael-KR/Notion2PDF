# Notion2PDF app icon

The icon represents a document becoming a PDF: a charcoal page, a conversion arrow, and a red PDF badge on a light macOS tile. The exterior is transparent.

- Source: `Notion2PDF.png`, generated with the built-in image generation tool.
- Bundle: `../dist/Notion2PDF.app/Contents/Resources/Notion2PDF.icns`.
- Rebuild: run `scripts/build_macos_app.sh` from the project root. Uses macOS `sips` and `iconutil` for standard 16–1024 pixel representations.
